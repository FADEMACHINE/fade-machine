# FADE MACHINE

**Brand:** Black • White • Grey • Red  
**Focus:** NFL AFC Against The Spread (ATS) Analytics

---

## Current Features
- Dark theme matching FADE MACHINE branding (Black, White, Grey, Red)
- All 16 AFC teams
- Sample historical ATS data for the past 5 seasons (2021–2025)
- Filters: Season, Division, Teams
- Aggregated ATS performance table
- Quick insights (Strongest / Weakest ATS teams)

> **Note:** Data is currently sample data for development. Real historical data will be connected later via APIs.

---

## How to Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Preview Without Running Python Every Time

Best free option: **Streamlit Community Cloud**

1. Go to https://share.streamlit.io
2. Sign in with your GitHub account
3. Deploy the `fade-machine` repository
4. You will get a permanent public link (example: https://fademachine.streamlit.app)

Once deployed, every time we update the code on GitHub, the live preview updates automatically.
